# AI SCORM Voiceover

## Summary
Adds text-to-speech voiceover playback to Moodle SCORM learning content.

## Description
AI SCORM Voiceover reads learner-facing SCORM text aloud with synchronized highlighting and teacher-controlled voice and language settings.

## Features
- Reads supported SCORM lesson text aloud from a toolbar.
- Highlights the text as it is spoken.
- Lets administrators and teachers configure available voices and languages.
